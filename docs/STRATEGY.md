## 2. 診断

1. **今のボトルネックは「題材のジャンル」ではなく「配信の当たり外れ」に見える（推測）。**
   登録者0のチャンネルでは初期サンプルが小さく、同じ日・同じ制作基準でも再生数が二極化した。
   4本だけが伸び、6本はほぼ配信されていない。ジャンル比較はこの分散に飲まれている。
2. **収益の計測が無い。** 再生数だけでは「成果1件」に近づいているか判定できない。
   Shortsの説明欄URLはクリックできないため、導線はプロフィールのhub経由。
   そのhubと動画の成果を分ける計測IDも未設定（D30）。
3. **手作業の詰まりが承認・公開の速度を落としている。** 固定コメント、楽天ログイン、
   Google AI モードのアップロード、Studioの公開切替はいずれも人手が必要で、
   いずれかが止まると週1本のリズムが崩れる。

## 3. 戦略の軸（4つ）

### A. ジャンルは維持し、勝ち型の探究は「動画単位」で行う

- E5を守り、次回以降も電気代ジャンルを継続する。スマホ設定への自動切替（E6/E7）はしない。
- ただし「電気代が勝ち型」とは扱わない。題材は一次資料が確認でき、
  **未使用の数値**（E8）で、1,500円以上の商品（Q4）が紐づくものだけを候補にする。
- `winter_three` は E3 のまま除外。

### B. 変えるのは「題材の当たり」ではなく、記録できる配信変数

今後4本は、同じ描画パイプライン（`render_yorimichi.py`）・尺35〜40秒・
PR／種別ラベル／出典の全編表示・CTA文面を固定し、**一度に1つだけ**変えて記録する。

| 変数 | 記録内容 |
| --- | --- |
| タイトル | 疑問形／金額／問題提起の別と文字数 |
| フック | 冒頭1〜3秒の絵とテロップ |
| 公開時刻 | `publish.json` の日付だけでなく、実時刻を `docs/ANALYTICS.md` に記録 |
| サムネイル | 生成物のIDと差分 |
| 指標 | 公開後48時間・7日の視聴回数、平均視聴割合、エンゲージメント、入手元内訳 |

- 数字は `docs/ANALYTICS.md` に日付付きで追記し、古い値を上書きしない（既存の運用を維持）。
- 人物を焦点にした語りは `docs/NARRATIVE_FORMAT.md` の試作を使う。比較変数は「人物中心かどうか」だけ。
- サンプルが少ない間は「傾向」としてだけ扱い、1本の生死で型を決めない（11/18の反省を維持）。

### C. 収益導線を先に計測可能にする

1. 楽天アフィリエイトに再ログインし、レポートで**サイト別**（チャンネル／hub）の
   成果件数・報酬を確認する。`docs/DECISIONS_PENDING.md` D30 の判断材料にする。
2. サイト別に分かれない場合は、リンク作成画面で**計測ID**を設定する（リンクの作り直しは不要、
   上限20個）。付与したIDと ⟷ slug / site の対応表を `docs/CHANNEL_SETUP.md` に残す。
3. 商品はQ4（単価1,500円以上）を維持。料率アップ商品は楽天画面で確認できたものだけを候補にし、
   推測で料率を書かない。
4. 固定コメント（PR入り）を上位4本と新作から手動でピン留めする。
   UIでできない場合は `PRODUCTION_LOG.md` に理由を残し、PRは動画本編＋説明欄で維持する。

### D. 規約と品質のゲートは緩めない

- `shorts-standard/` の標準、`approve.py` / `gate.py` の停止条件、全編PR・AI/模式図ラベル・
  出典表示を維持する。効能効果・商品画像・レビュー本文・一次資料なき数値は使わない。
- Google AI モードのレビューは継続。アップロードが0%で止まったら60秒で失敗させ、
  時間をおいて再試行する（Museへの逆戻りはしない）。
- `tv_eco_mode` の公開済み動画に対する指摘は、**まず公開版の該当フレームを目視して**
  実在を確認する。実在すれば WORKFLOW §8 の「軽微」（視認性）として説明欄・固定コメントで
  告知し、動画は残す。差し替えが必要ならオーナー判断で新IDを検討する（旧IDは非公開で残す）。

## 5. 中間レビューの判定規則（12/28）

- 新作4本のうち**2本以上が48時間で1,000回超**: この型を維持し、同じ変数設定で継続。
- **1本以下**: 新規題材の制作を止め、公開時刻・フック・サムネイルをオーナーと見直す。
  ジャンル切替はまだしない（データが足りないため）。
- **成果が1件でも発生**: その動画のリンク／商品／導線を記録し、同じ導線を他本に横展開する。
  ただし量産はしない（AGENTS.md §2）。
- **規約・法規の疑義が1件でも発生**: 公開を止め、WORKFLOW §8 に従って対応する。
