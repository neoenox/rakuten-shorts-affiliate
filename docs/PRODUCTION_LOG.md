## 2026-11-17 追記 `kaito_plate`：BGMと FreeVideo の動画背景

**成果物**: `out/draft/kaito_plate_DRAFT.mp4`（34.34秒 / 1080x1920 / 17.4MB）を差し替え。

### 音楽（BGM）

- 魔王魂「ピアノ39」（作曲：森田交一）を `assets/bgm/maou_bgm_piano39_maoudamashii.mp3` に置いて使用。

- `sidechaincompress` でナレーションの間だけ自動で下げ、`amix` → `loudnorm=I=-14`。
  実測 **-14.3 LUFS / True Peak -1.2 dBFS**。声と声の間の BGM は -27〜-33 dBFS。
- クレジットは説明欄に自動で入る（`render.json` の `bgm.credit`）。
- 条件とリスク（Content ID の誤主張があり得る）は [`RIGHTS_LEDGER.md`](RIGHTS_LEDGER.md)。

- シーン1・2・4の背景を、静止画から**短い動画クリップ**に差し替えた（`scripts/gen_freevideo.py`）。
- 生成条件: 544x960 / 7.0秒指定 → 出力7.29秒・24fps・175フレーム。`two_pass`・8+3ステップ・`upscale_factor=2`。
  実測の所要は **248〜538秒/本**（RTX 4060 8GB、空きRAMが少ないと遅い）。
- シーン1は最初の出力に「湯気／煙」が入り、冷凍肉として誤読しうるので**作り直した**（`scene1b`）。
  2本目は真上からの霜のついた肉になり、台本の visual に合った。
- クリップは 1080x1920 に cover → 30fps の連番JPEGに展開し、`unsharp` で軽く輪郭を戻してから使う。
  クリップがシーンより長い場合は頭から切る（1: 7.30→3.67秒、2: 7.30→6.14秒、4: 7.30→6.57秒）。
- 生成される音声（`audio_use: reference`）は使わない。プロンプトに `no background music` を入れて、スコアを `N/A` にしている。

### 確認したこと（差し替え後）

- フレーム抽出6点: 動画背景でも「PR」「イメージ（AI生成）」「模式図」「キャプション」「出典」は全て読める。
- ffprobe: 1080x1920 / 30fps / 1030フレーム / 34.34秒 / h264 + aac。

### 残件（変わらず）

1. 楽天ROOMのURL（チャンネル作成とサイト登録が前提）。
2. 解凍の速さの根拠が販売元1社のみ。
3. `needs_review` のため `out/draft/` のまま。

### 次に試すなら

## 2026-11-17 2本目 `ac_heater_saving`（エアコン暖房・1℃ vs 掃除）

**成果物**: `out/draft/ac_heater_saving_DRAFT.mp4`（39.47秒 / 1080x1920 / 11.2MB）

### 題材と根拠

資源エネルギー庁の省エネポータル（空調ページ）に、同じ条件で比較できる行動別の試算があった。
東京をモデルとした木造南向き住宅（JIS C 9612:2013）、エアコン2.5kW、電気31円/kWh（令和4年7月の新電力料金目安単価）。

| 行動 | 年間 | 出典 |
| --- | --- | --- |
| 設定温度を1℃下げる | 15.80kWh / 約490円 | 空調ページ |
| 1日1時間だけ短くする | 35.68kWh / 約1,110円 | 同上 |
| フィルターを月1〜2回掃除する | 37.90kWh / 約1,170円 | 同上（風量20%低下を想定） |

「我慢して1℃下げる（年490円）より、掃除（年1,170円）」という判断の話にした。

### 素材

- 情景2点は **FreeVideo** のクリップ（シーン1: 暖房の部屋 242秒 / シーン6: フィルターを外す手元 245秒）。
- 図解5点は **PIL**（`art/build_art.py`）。棒グラフは「同じ構図で棒が1本ずつ増える」3枚を作り、
  まだ出していない行は「？」の枠にした。
- BGMは曲を変えた（魔王魂「ピアノ41」）。定型BGMの使い回しを避ける方針。

### 確認したこと

- `check`: ERROR 0。
- 全編デコード: エラーなし。
- ラウドネス: -14.4 LUFS / True Peak -1.3 dBFS。
- 目視: PR全編、出典ラベル、条件の注記（31円/kWh は令和4年7月単価）が出ている。
  シーン7の「プロフィールのリンクへ」がキャプション帯に隠れていたので、模式図の配置を直した。

### 残件

1. 商品（エアコン用の掃除ブラシ等）の特定と、アフィリエイトリンクの作成。
2. 「実際の家庭での削減額は条件次第」である旨は説明欄に入れた（`description_note`）。
3. `status` は `needs_review` のまま。

### 学んだこと

- 図解を「1本ずつ増える」連番にすると、同じ構図で説明が進むので視線が安定する。
- 模式図の下端はキャプション帯（y=1252〜）に隠れる。要素は y<1240 に収める。

### 2026-11-17 修正（指摘3点＋はみ出し）

指摘への対応と、原因の記録。

1. **読みがおかしい**
   - `年約490円` が「としやく」と読まれていた。`年いくら` も「としいくら」。`1℃` は「いちどしい」。
   - `shorts/ac_heater_saving/pron.json` に `年約→ねんやく` / `年いくら→ねんいくら` / `1℃→いちど` を入れて修正。
   - 確認は VOICEVOX の `audio_query` が返す `kana` を目で読む方法で行った（`年約` のような二字熟語は要確認）。

2. **音楽が小さい**
   - 原因: 最終段に `loudnorm` を置いていたため、BGM のゲインを上げると全体が押し戻され、相対レベルがほぼ変わらなかった。
   - 対策: ミックスを一度WAVに書き出して loudness を測り、**2パス目の linear loudnorm**（定ゲイン）で -14 LUFS に合わせる方式へ変更。
     さらに `alimiter` を入れて True Peak を -1.9 dBFS に収めた。
   - 設定: `gain_db: -5` / `duck: ratio 3, release 200ms`。声と声の間の BGM は約 -25 dBFS（声は -18 dBFS 前後）。

3. **ブラシのイメージが欲しい**
   - シーン7の図解（スマホのモック）を、掃除用ブラシのイメージ写真（ChatGPTで生成・文字とロゴなし）に差し替えた。
   - `art_types` の 7 を `ai` に変更。スマホのモックは説明欄の案内に残る。

4. **文字が枠からはみ出していた**
   - シーン5の「住宅」ボックス: 2行の値が枠の下端を越えていた（高さ150pxに対し文字が153px）。
     ボックスを168pxに広げ、文字を33px・行間6pxに調整。
   - シーン4の棒グラフ: 数値ラベルが右端（x=1071/1080）に寄りすぎていた。
     バー長を430px、ラベルを38pxに縮めて、右端に余白を残した。

最終: 39.03秒 / -14.0 LUFS / True Peak -1.9 dBFS。
