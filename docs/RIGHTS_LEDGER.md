### 商品画像を「見て、文章に起こして、生成する」場合（2026-11-17 追加）

元画像を生成AIに入力しないので、**楽天規約の「画像の収録・加工」には当たらない**。著作権も、依拠性の議論は弱まる（文化庁は Image to Image を依拠性が認められやすい例として挙げている）。ただし**「似ているか」は別問題**として残る。

| 層 | 判断 |
| --- | --- |
| 著作権（商品写真） | 類似性＋依拠性の両方が必要。**写真の構図・ライティング・配置をなぞると類似性が上がる**ので、抜き出すのは「形・色・素材・寸法」といった事実だけにする |
| 楽天規約 | 画像を見るのは自由、事実を自分の言葉で書くのも自由。ただし商品ページの文章の複製やレビューの転載は不可 |
| 商標 | ロゴ・ブランド名・パッケージは再現しない（商標法2条3項7号・8号） |
| 意匠 | 特定商品の独特の形状を再現しない（意匠法23条。映像が「実施」に直ちに当たるとは限らないが紛争リスク） |
| 景表法 | 実物と違う外観を商品紹介に使うと優良誤認。AI画像は必ず「イメージ（AI生成）」と明記し、「これが商品です」と言わない |

線引き: ○事実（材質・寸法・色・機能・価格）→ 汎用の情景を生成 ／ △実物に寄せる ／ ✕ロゴ・パッケージ・固有形状の再現、写真の構図をなぞる、元画像の入力。

**法的助言ではない。** 判断が難しい商品（意匠登録・有名ブランド）は、その動画では商品を映さない側に倒す。

## 3. 表記のまとまり（毎回そろえる）

1. 動画の全編に「PR」を焼き込む（冒頭だけでは不足）。
2. サムネイル・固定コメント・説明欄の冒頭にも「PR」。
3. AI生成の映像には「イメージ（AI生成）」、自作の図には「模式図」。
4. 音声・音楽のクレジットを説明欄に書く。
5. 出典URLは説明欄に全て書く（画面には短いラベルだけ）。
