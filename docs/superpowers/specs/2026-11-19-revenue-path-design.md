# 収益導線の設計（商品一覧ページ＋導線の役割分担）

作成: 2026-11-19。オーナー承認済み（設計はチャットで合意）。

## 1. 背景（実測）

- Shorts の**説明欄URLはタップできない**（YouTubeヘルプ）。
- ただし **固定コメント内のURLはクリックできる**（`youtube.com/redirect?...&q=<hb.afl>` として描画されることを2026-11-19に確認）。
- **チャンネルのリンク欄にも楽天リンクが入っている**（2026-11-19時点ではブラシ商品のリンク）。
- したがって「商品への道が無い」のではなく、**道が2本ある状態**。問題は役割が決まっていないこと。

## 2. 決めたこと

| 面 | 行き先 | 理由 |
| --- | --- | --- |
| チャンネルのプロフィールリンク | **商品一覧ページ（hub）** | 動画をまたいで溜まる。過去動画の視聴者も自分の商品にたどり着ける |
| 各動画の固定コメント | **その動画の商品へ直リンク** | 動画と商品が1対1で一致する |
| 説明欄 | 商品名とリンク（テキスト） | タップできないが、コピーとクロールのため残す |

## 3. hub の仕様

- 置き場所: GitHub Pages の公開リポジトリ `kurashi-hantei`（この作業リポジトリとは別）。
  URL: `https://neoenox.github.io/kurashi-hantei/`
- 形: 静的 HTML 1枚。ビルドなし。モバイル優先（縦1列、最大幅 720px）。
- 内容:
  - チャンネル名と一行の説明
  - **アフィリエイト広告を含む旨の明示**（ページ上部）
  - 商品カード: 商品名 / 紹介した動画のタイトル / 「楽天で見る」リンク（`rel="nofollow sponsored"`）
  - ショップ名は出さない（2026-11-19 改訂）。`render.json` / `publish.json` に表示名のデータが無く、
    URL のパスにあるのは店舗コード（`auc-mikawa-kiko` 等）で利用者向けの名前ではない。
  - チャンネルへのリンク
- **載せないもの**: 価格（変動する）、商品画像（楽天の画像は複製・改変が禁止）、レビュー本文、未検証の数値。

## 4. 生成方法

`scripts/build_hub.py` が `shorts/*/publish.json` と `render.json` を読み、**clone 済みの公開リポジトリ**
（既定 `../kurashi-hantei`）の `index.html` を書き換える。手書きしない。

- 対象: `publish.json` の `visibility` が `public` のものだけ。
- 並び: `published_at` の新しい順。
- 出力は1ファイル完結（CSSはインライン）。
- **正は公開リポジトリの `index.html` 1つ。このリポジトリに写しは置かない**（`hub/` は廃止）。
- 既定の実行（フラグ無し）は「書き込み＋検査＋差分表示」。`--deploy` で commit と push まで進む。
- `--verify` はリンクの生存確認だけ（書き込みなし）。`--allow-remove` はカードが減る変更の明示許可。

### deploy の停止条件（fail-closed）

1. 検査 FAIL（PR表記・画像なし・価格なし・全リンク・`rel`）
2. clone が無い／git 管理外
3. clone に未 commit の変更（`index.html` の未 commit だけは許す）
4. `origin/main` と HEAD がずれている
5. カードが減る（`--allow-remove` が無いとき）
6. 差分ゼロ → 何もせず成功

commit は作者を `neoenox` に固定し、件名 `hub: 公開{n}件を反映（YYYY-MM-DD）`、本文に増減カードを書く。

## 5. 運用

1. 動画を公開したら `publish.json` を更新 → `python scripts/build_hub.py --deploy`。
2. 楽天アフィリエイトに hub を**別サイト**として登録する（2026-11-19 決定）。
   運営サイト名「暮らしの判断メモ（商品一覧）」、URL は hub、ジャンルは既存と同じ、順位は3位。
3. チャンネルのプロフィールリンクを hub に差し替える。表示名は「紹介した商品一覧（PR）」。
   外部リンク枠は1本なので、既存のリンク（掃除用ブラシ）を編集するか削除して追加する。

## 6. 検証

- hub が HTTPS で開き、スマホ幅（375px）で崩れない。
- 各カードのリンクが 301 で `item.rakuten.co.jp` に着地し、`scid=af_pc_etc` が付く。
- 楽天アフィリエイトのサイト一覧に hub が載る。
- チャンネルのリンク欄が hub を指す。
- ページに PR 表記がある。

## 7. やらないこと

- 価格・在庫・レビューの表示（変動と規約のため）。
- 商品画像の使用（規約）。
- 常時稼働の自動デプロイ（人が `--deploy` を叩く1コマンドだけ）。
- hub 専用のリンクIDによる成果の分離（2026-11-19 決定。最初のレポートでサイト別に分かれるかを見てから判断する）。
- リンク切れカードの自動削除（検出は `--verify`、対応は人）。
